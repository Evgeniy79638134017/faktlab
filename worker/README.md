# Приём заявок с сайта → Telegram

Форма на сайте отправляет заявку не в почтовую программу, а на Cloudflare Worker. Worker кладёт её в Telegram. Токен бота живёт в секретах Cloudflare — в коде сайта его нет.

```
браузер посетителя  →  POST на Worker  →  Telegram Bot API  →  ваш чат
```

## Что нужно сделать один раз

**1. Завести бота (2 минуты, делает Евгений).**

В Telegram открыть [@BotFather](https://t.me/BotFather) → `/newbot` → имя, например «ИИщенко LAB — Заявки» → username, например `ilab_zayavki_bot`. BotFather пришлёт токен вида `1234567890:AAH...`.

**Сразу после этого открыть диалог со своим новым ботом и нажать «Начать» (/start).** Telegram не даёт боту писать первым: пока вы не написали ему, заявки уходить не будут.

**2. Положить токен в проект** — файл `Главный\.telegram_config\.env`, новой строкой:

```
SITE_FORM_BOT_TOKEN=1234567890:AAH...
```

Строка нужна, чтобы токен не потерялся между сессиями. В сам сайт он не попадает.

**3. Вход в Cloudflare.** В терминале, из папки `worker`:

```bash
wrangler login
```

Откроется браузер, там подтвердить доступ. Если аккаунта Cloudflare нет — регистрация бесплатная, карта не нужна.

**4. Деплой и секреты:**

```bash
wrangler deploy
```

```bash
wrangler secret put BOT_TOKEN
```

```bash
wrangler secret put CHAT_ID
```

`BOT_TOKEN` — токен из BotFather. `CHAT_ID` — куда слать: ваш личный id в Telegram (узнать можно у @userinfobot). Если заявки нужны в общий чат — id группы, начинается с минуса.

После `wrangler deploy` в выводе будет адрес вида `https://ilab-form.<ваш-поддомен>.workers.dev`. Его нужно вписать в `index.html` сайта:

```html
<script>window.SITE_CONFIG = { formEndpoint: "https://ilab-form.xxx.workers.dev" };</script>
```

## Проверка

```bash
curl -X POST https://ilab-form.xxx.workers.dev -H "Content-Type: application/json" -d "{\"name\":\"Проверка\",\"contact\":\"+7 000\",\"type\":\"тест\",\"msg\":\"тестовая заявка\"}"
```

Ответ `{"ok":true}` и сообщение в Telegram — значит, всё работает. Дальше отправить заявку с самого сайта.

## Домены

В `worker.js`, массив `ALLOWED`, перечислены адреса, с которых Worker принимает заявки: боевой домен **faktlab.ru** (с www и без) и локальный адрес для проверки. Запросы с чужих сайтов отбиваются, чтобы вашим ботом не пользовались посторонние. При смене домена — поправить массив и сделать `wrangler deploy` заново.

## Защита

- Токен в секретах Cloudflare, не в коде страницы.
- Приём только с наших доменов.
- Скрытое поле-ловушка: боты его заполняют, люди не видят. Такие заявки молча отбрасываются.
- Длина полей ограничена, разметка экранируется — через форму нельзя прислать вредоносный текст.

## Бесплатный лимит

100 000 запросов в сутки на бесплатном тарифе Cloudflare. Для формы на сайте это с многократным запасом.
