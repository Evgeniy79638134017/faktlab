# Публикация faktlab.ru

Сайт статический: HTML, CSS, JS без сборки. Публикуется на GitHub Pages, домен от Рег.ру.

## 1. Репозиторий

Локальный git уже создан, история есть. Осталось создать удалённый и запушить:

```bash
gh repo create faktlab --public --source=. --remote=origin --push
```

Если `gh` не установлен — создать репозиторий вручную на github.com и выполнить:

```bash
git remote add origin https://github.com/<аккаунт>/faktlab.git
git branch -M main
git push -u origin main
```

Токен для доступа лежит в `Главный\.telegram_config\.env`, строка `GH_PAT`.

## 2. Включить Pages

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
В поле **Custom domain** вписать `faktlab.ru`. Файл `CNAME` в репозитории уже есть, GitHub подхватит его сам.

## 3. DNS у Рег.ру

В карточке домена → «DNS-серверы и управление зоной» удалить A-записи парковки (`95.163.244.138`) и добавить четыре A-записи для `@`:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

Для `www` — запись CNAME на `<аккаунт>.github.io.`

Изменения расходятся от получаса до нескольких часов. Проверка:

```bash
nslookup faktlab.ru 8.8.8.8
```

## 4. Сертификат

После того как DNS разошлись, в **Settings → Pages** дождаться выпуска сертификата (обычно 10–30 минут) и включить **Enforce HTTPS**.

## 5. Проверка после публикации

- открыть `https://faktlab.ru` и `https://faktlab.ru/cases.html`;
- отправить тестовую заявку — она должна прийти в Telegram. Если не приходит, смотреть консоль браузера: ошибка про источник запроса означает, что домен не совпал со списком в `worker/worker.js`;
- проверить страницы политики, согласия и условий;
- убедиться, что `https://faktlab.ru/sitemap.xml` и `robots.txt` открываются.

## Что не выложено в репозиторий

Служебные файлы исключены через `.gitignore`: состояние задачи, промпты визуала, инструкции по сборке, резервные копии. Секретов в репозитории нет — токен бота и chat_id хранятся в секретах Cloudflare.
